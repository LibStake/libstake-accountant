# 배포 · 환경

> 어디에·어떻게 올리는가. 환경 키의 권위 목록은 [`.env.default`](../../.env.default)(이름·값은 코드/설정이 SOT, 루트 §0.9).

## 호스팅

- Next.js를 Vercel에 배포한다 — 정적 자산과 서버 함수(라우트 핸들러·서버 액션)를 함께.
- Firestore는 관리형으로 두고 서버에서 Admin 자격으로 접근한다([`overview.md`](./overview.md)).
- 데이터 지역은 주 사용자(KST)에 가깝게 둔다.

## 환경 · 시크릿

[`.env.default`](../../.env.default)가 키 목록의 권위다. 용도별로:

- **DB 관리자 자격** — 서버의 Firestore Admin 접근.
- **세션 서명 시크릿** — 세션 토큰 서명·검증([`auth.md`](./auth.md)).
- **해시 페퍼(비밀번호·PIN)** — 자격증명 해싱([`auth.md`](./auth.md)).
- **배포 토큰** — 보안 규칙·인덱스 등 Firebase 구성 배포(CI).
- 시크릿은 호스팅 환경 변수로 주입하고 리포지토리에 담지 않는다.

## 데이터베이스 구성

- 보안 규칙은 클라이언트 직결을 차단한다([`auth.md`](./auth.md)). 서버 질의에 필요한 인덱스를 함께 형상관리한다.
- 규칙·인덱스 변경은 배포 토큰으로 CI에서 반영한다.

## 비용 자세

- 관리형 서비스의 무료/저비용 구간에 맞춰 운영비 최소를 목표로 한다([`../service-specs/overview.md`](../service-specs/overview.md)).
