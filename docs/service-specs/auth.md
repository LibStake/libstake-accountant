# 인증

> 로그인과 빠른 잠금해제.

## 시나리오 — 로그인 / 빠른 잠금해제

1. 접속하면 인증을 거친다. 처음이거나 유효기간이 지난 브라우저면 **이메일 + 비밀번호**로 로그인한다.
2. 한 번 로그인한 브라우저는 유효기간 동안 기억된다 → 다음 접속 시 **숫자 PIN 키패드**가 떠 PIN만으로 들어간다.
3. 키패드 화면엔 항상 **"일반 로그인으로"** 버튼이 있어 이메일+비밀번호로 전환할 수 있다.
4. PIN을 여러 번 틀리면 그 브라우저의 빠른 로그인이 풀리고 일반 로그인을 요구한다.

## 규칙

- 자격증명(이메일·비밀번호·PIN)은 해시해 안전하게 저장한다. 인증은 토큰 기반.
- 여러 사용자가 각자 이메일+비밀번호로 가입·로그인하며, 각 사용자의 데이터는 서로 격리된다(사용자 단위 스코프).
- **빠른 PIN 자격**: 풀 로그인한 브라우저만, 유효기간 안에서 PIN 키패드를 받는다. 유효기간이 지나면 풀 로그인으로 되돌아간다.
- **PIN 무차별 방지**: PIN은 그 브라우저에 한해 검증되며, 연속 실패가 한도를 넘으면 그 브라우저의 빠른 로그인을 해제한다.

## 기본값

- PIN: 6자리 숫자, 디바이스 유효기간 30일.
- PIN 실패: 5회 초과 시 풀 로그인으로만 복구(추가 쿨다운 없음).
