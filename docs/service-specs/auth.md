# 인증

> 가입·로그인·빠른 잠금해제와 계정·기기 관리.

## 시나리오 — 가입

1. 이메일 + 비밀번호로 가입한다(이메일은 로그인 식별자, 별도 검증 없음).
2. 가입 후 로그인하면 자기 가계부를 쓴다.

## 시나리오 — 로그인 / 빠른 잠금해제

1. 접속하면 인증을 거친다. 처음이거나 유효기간이 지난 브라우저면 **이메일 + 비밀번호**로 로그인한다.
2. 풀 로그인한 브라우저에서 **PIN을 설정**하면, 유효기간 안에서는 다음 접속 시 **숫자 PIN 키패드**로 들어간다.
3. 키패드 상태에서도 언제든 이메일+비밀번호 로그인으로 전환할 수 있다.
4. PIN을 여러 번 틀리면 그 브라우저의 빠른 로그인이 풀리고 일반 로그인을 요구한다.

## 시나리오 — 비밀번호 분실

1. 외부 복구 채널이 없으므로, 빠른 로그인(PIN)이 살아 있는 기기에서 PIN으로 들어온다.
2. 계정 설정에서 현재 비밀번호 없이 새 비밀번호를 정한다(신뢰된 기기).
3. 빠른 자격이 있는 기기가 없으면 자동 복구 수단은 없다.

## 규칙

- 자격증명(이메일·비밀번호·PIN)은 해시해 안전하게 저장한다. 인증은 토큰 기반.
- 여러 사용자가 각자 이메일+비밀번호로 가입하며, 각 사용자의 데이터는 서로 격리된다(사용자 단위 스코프).
- **이메일 식별자**: 이메일은 로그인 식별자로만 쓰고 메일 발송·검증은 하지 않는다.
- **빠른 PIN 자격**: 풀 로그인 후 PIN을 설정한 브라우저만, 유효기간 안에서 PIN 키패드를 받는다. 유효기간이 지나면 풀 로그인으로 되돌아간다.
- **PIN 무차별 방지**: PIN은 그 브라우저에 한해 검증되며, 연속 실패가 한도를 넘으면 그 브라우저의 빠른 로그인을 해제한다.
- **PIN 관리**: 풀 로그인 상태에서 PIN을 설정·변경·해제한다. 해제하면 그 브라우저는 풀 로그인으로 되돌아간다.
- **비밀번호 변경/재설정**: 풀 로그인에서는 현재 비밀번호를 확인해 바꾼다. 빠른 로그인(PIN)으로 들어온 기기에서는 현재 비밀번호 없이 재설정한다(신뢰된 기기). 변경 시 다른 브라우저의 빠른 로그인 자격을 모두 해제한다.
- **분실 복구 한계**: 외부 채널(이메일 등)을 쓰지 않으므로, 빠른 로그인(PIN)이 살아 있는 기기가 없으면 비밀번호 분실 시 복구 수단이 없다.
- **로그아웃**: 현재 브라우저의 세션을 끝낸다. 빠른 로그인 자격까지 해제할지는 선택한다.
- **기기 관리**: 빠른 로그인 중인 브라우저 목록을 보고 개별 해제할 수 있다. 해제된 브라우저는 풀 로그인을 다시 요구한다.
- **계정 삭제**: 본인 확인 후 계정과 그 사용자의 모든 데이터를 영구 삭제한다. 되돌릴 수 없다.

## 기본값

- PIN: 6자리 숫자, 디바이스 유효기간 30일.
- PIN 실패: 5회 초과 시 풀 로그인으로만 복구(추가 쿨다운 없음).
