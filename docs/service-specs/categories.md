# 카테고리

> 거래를 분류하는 라벨.

## 도메인

- **카테고리(Category)** — 거래·정기 거래에 붙는 분류 라벨. 종류(지출/수입)와 **무관**하며 양쪽에 쓸 수 있다.
- 기본 시드를 제공하고, 사용자가 추가·수정·삭제한다.

## 규칙

- 카테고리는 종류(지출/수입)를 갖지 않는다([`transactions.md`](./transactions.md)).
- 삭제: 사용 중이면 먼저 사용 건수를 확인한다. 진행하면 그 카테고리를 쓰던 거래·정기 거래의 카테고리만 비우고(미분류) 삭제한다 — 거래 자체는 보존(결제수단 삭제와 같은 패턴, [`payment-methods.md`](./payment-methods.md)).
