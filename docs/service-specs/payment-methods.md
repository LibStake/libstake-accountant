# 결제수단

> "무엇으로 냈는지"를 나타내는 카드/계좌 라벨. **잔액은 다루지 않는다.**

## 시나리오 — 카드/계좌 관리

1. 관리 화면에서 카드/계좌를 추가한다(이름 · 종류).
2. 거래·정기 거래 등록 시 결제수단으로 선택할 수 있다(선택 사항).
3. 더 이상 안 쓰는 항목은 **아카이브**(선택 목록에서 숨김, 관리 화면엔 남음)하거나 **완전 삭제**한다.

## 도메인

- **결제수단(Payment method)** — 카드 또는 계좌. 거래·정기 거래에 선택적으로 붙는 라벨이며 잔액·한도·이체를 추적하지 않는다.

## 규칙

- 거래·정기 거래에 선택적으로 붙는다(없어도 됨). 종류(카드/계좌)는 생성 후 바꿀 수 없다.
- **아카이브**: 선택 목록에서만 숨기고 관리 화면·기존 거래 표시에는 남긴다. 되돌릴 수 있다.
- **완전 삭제**: 사용 거래가 있으면 먼저 확인한다. 진행하면 그 결제수단을 쓰던 거래·정기 거래의 결제수단만 비우고 거래는 보존한다.
- **기본 결제수단**: 사용자가 하나를 기본으로 지정할 수 있다. 거래 입력 시 기본값으로 선택되며 바꿀 수 있다([`transactions.md`](./transactions.md)). 아카이브·삭제하면 기본 지정도 풀린다.
- **표시 순서**: 사용자가 선택 목록·관리 목록의 표시 순서를 정한다.
