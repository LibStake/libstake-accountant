# 인증 화면

> 가입·로그인·PIN 잠금해제의 진입 게이트. 인증 규칙은 [`service-specs/auth.md`](../service-specs/auth.md). 로그인 후 계정·보안은 [`account.md`](./account.md).

## 목적

접속자를 인증해 본인 가계부로 들여보낸다. 신규는 가입, 재방문은 PIN으로 빠르게.

## 구성

- **가입** — 이메일·비밀번호로 즉시 가입(이메일 검증 없음).
- **풀 로그인** — 이메일·비밀번호. 처음이거나 빠른 자격이 없을 때.
- **PIN 키패드** — 빠른 자격이 있는 브라우저에 뜨는 숫자 키패드. 항상 **"일반 로그인으로"** 전환을 둔다.

## 흐름

- 진입 → 빠른 자격이 있으면 PIN 키패드, 없으면 풀 로그인(판정은 [`service-specs/auth.md`](../service-specs/auth.md)).
- 가입 → 곧바로 로그인(검증 단계 없음).
- PIN 연속 실패가 한도를 넘으면 풀 로그인으로 강제 전환된다(한도는 [`service-specs/auth.md`](../service-specs/auth.md)).
- 비밀번호 분실 시, 빠른 로그인(PIN)이 살아 있는 기기로 들어와 계정에서 재설정한다([`account.md`](./account.md)). 그 기기가 없으면 복구 수단이 없다.
- 통과 후 기본 랜딩(입력)으로([`navigation.md`](./navigation.md)).

## 상태

- 로그인·가입 실패는 입력값을 보존하고, 계정 존재 여부를 노출하지 않는 사유로 표시한다([`patterns.md`](./patterns.md)).
- PIN 오입력은 즉시 피드백하되 남은 시도를 과하게 노출하지 않는다.
