# 계정 · 보안

> 로그인 정보·PIN·기기·탈퇴 관리. 규칙은 [`service-specs/auth.md`](../service-specs/auth.md). 가입·로그인 게이트는 [`login.md`](./login.md).

## 목적

로그인한 사용자가 자기 계정의 보안과 기기 접근을 관리한다. 요약에서 진입([`navigation.md`](./navigation.md)).

## 구성

- **비밀번호 변경/재설정** — 현재 비밀번호 확인 후 변경. 빠른 로그인(PIN)으로 들어온 경우엔 현재 비밀번호 없이 재설정한다(기기 신뢰, 규칙은 [`service-specs/auth.md`](../service-specs/auth.md)).
- **PIN** — 이 브라우저의 빠른 로그인 PIN 설정·변경·해제.
- **기기** — 빠른 로그인 중인 브라우저 목록과 개별 해제.
- **로그아웃** — 현재 세션 종료. 이 기기의 빠른 로그인까지 해제할지 선택.
- **계정 삭제** — 계정과 모든 데이터 영구 삭제.

## 흐름

- 비밀번호 변경·기기 해제는 해당 브라우저의 빠른 로그인 자격을 푼다(규칙은 [`service-specs/auth.md`](../service-specs/auth.md)).
- 계정 삭제는 되돌릴 수 없어 확인 다이얼로그를 거친다([`patterns.md`](./patterns.md)).

## 상태

- 보안에 영향 주는 동작(기기 해제·로그아웃·삭제)은 결과를 분명히 확인시킨다.
