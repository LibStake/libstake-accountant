# 입력 화면

> 거래 한 건을 즉시 기록하는 기본 랜딩. 거래 규칙·필드는 [`service-specs/transactions.md`](../service-specs/transactions.md).

## 목적

결제 직후 한 손으로 한 건을 남긴다. 인증 후 첫 화면([`navigation.md`](./navigation.md)).

## 구성

- 금액이 시각적 주인공 — 가장 크게, 먼저 입력.
- 항목명(필수) · 카테고리 · (선택) 결제수단 · 메모.
- 종류(지출/수입) 전환.
- 발생일시는 자동으로 채워지고 그 자리에서 수정 가능.
- 카테고리·결제수단은 피커로 고른다(목록 관리는 [`settings.md`](./settings.md)).
- 기본 결제수단이 지정돼 있으면 입력 시 자동 선택된다(규칙은 [`service-specs/payment-methods.md`](../service-specs/payment-methods.md)).
- 폼 아래에 최근 입력 몇 건을 컴팩트하게 보여 중복 입력을 막는다.
- 저장은 하단에 고정하고 그 위 영역만 스크롤한다.

## 흐름

- 입력 → 저장 → 폼 즉시 비움, 최근 입력 목록도 갱신해 같은 화면에서 다음 입력에 대비([`patterns.md`](./patterns.md)).
- 저장 성공은 비차단 토스트로만 알린다.
- 입력한 건의 수정·삭제는 내역에서([`history.md`](./history.md)).

## 폼팩터

- 모바일: 숫자 키패드·피커를 하단 엄지 범위에. 한 화면에서 완결.
- 데스크탑: 한 줄에 더 많은 필드, 키보드 입력 우선.
