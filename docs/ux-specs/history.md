# 내역 화면

> 기간 단위 거래 리스트와 개별 수정/삭제. 거래 규칙은 [`service-specs/transactions.md`](../service-specs/transactions.md).

## 목적

한 기간의 거래를 훑고, 잘못된 건을 고치거나 지운다.

## 구성

- 단위 전환(일·월·연), 기본=오늘(일). 한 번에 한 기간만 본다(무한 스크롤 아님).
- 기간 이동(이전/다음)으로 같은 단위의 다른 기간을 조회.
- 거래 행: 항목명·금액·카테고리·결제수단·발생일시. 지출/수입은 부호로 구분(색 규칙은 [`overview.md`](./overview.md)).
- 정기 거래에서 생성된 건은 출처를 표시([`recurring.md`](./recurring.md)).
- 항목명 검색 + 카테고리·결제수단·종류 필터로 좁힌다(규칙은 [`service-specs/transactions.md`](../service-specs/transactions.md)).
- 시간 오름차로 배열해 최신을 가장 아래에 둔다.
- 하단에 그 기간의 총 금액(순액)을 항상 노출한다(색 규칙은 [`overview.md`](./overview.md)).

## 흐름

- 행 선택 → 수정 또는 삭제.
- 영구 삭제는 확인 다이얼로그를 거친다([`patterns.md`](./patterns.md)).
- 단위·기간을 바꾸면 리스트만 갱신되고, 진입 시 최신(최하단)으로 내려둔다.

## 상태

- 기간·단위 전환과 총 금액은 고정하고, 리스트 영역만 스크롤한다.
- 그 기간에 거래가 없으면 빈 상태로 입력을 유도한다([`entry.md`](./entry.md)).
